# woojoocatDiscordBot

🐈‍⬛🚀 우주냥 보내기 (woojoocat)

디스코드 강화게임 봇. 우주선을 타고 떠나는 고양이 "우주냥"을 키우고 보내는 컨셉.

현재 초기 세팅 단계. 스터디 진행하며 내용 업데이트 예정.

환경변수 설정
`.env` 파일을 만들어 Discord 토큰을 넣어 주세요.

예시:
DISCORD_TOKEN=your_token_here

프로젝트 개요
프로젝트명: 우주냥 보내기
모티브: 강화게임 (디스코드 냥냥봇) — https://m.blog.naver.com/dosi_3642/222439655703
테마: 우주 및 우주선, 고양이
레포명: woojoocatDiscordBot
형태: 디스코드 봇 (웹앱 → 디스코드 봇으로 방향 전환)
핵심 기능
내 우주냥 생성
우주냥 보내기 (km 증가/감소)
우주냥 파괴 (적은 확률로 강제 삭제)
내 우주냥 삭제
내 우주냥 보기 (조회)
보내기 쿨타임 적용
스터디 진행 방식 (AI 사용 규칙)

기본 베이스는 손코딩, AI는 아래 범위 내에서만 사용.

AI 도구: 안티그래비티 CLI
질문 정도만 허용. 질문할 때는 "코드를 직접 수정하지마"라고 명시할 것
AI가 출력한 코드 복붙 금지 → 손으로 직접 타이핑
자동완성 금지
기술 스택

기존 웹앱 버전은 React.js + Next.js + TypeScript(풀스택)로 계획했으나, 디스코드 봇으로 전환하며 재검토 필요. 미확정.
